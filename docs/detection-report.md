# Detection report: Phase 3 baselines

> Generated by `scripts/detection_report.py` on 2026-11-19 (detection 0.1.0, pipeline 0.2.0). Numbers only; interpretation and limitations are in
> [ADR 0021](decisions/0021-detection-methodology.md). Full results: [detection/results.json](detection/results.json).

**Method in one paragraph.** Each file-hour is one window. A faulty window is scored only when its fault could physically show for at least 30 minutes; a normal window when at least 30 minutes were steady. Simulated split: train days 0-59, val days 61-80, test days 82-100. Experimental split: leave one season out; threshold tuned on the next season; trained on the other two. Each alarm threshold is the lowest value that keeps false alarms at or below 5% of normal validation windows, then it is frozen before test windows are scored. Detectors abstain where outdoor air is outside the range seen in fault-free training; abstained windows count as no alarm.

**Reading the numbers.** Recall and ROC-AUC don't depend on how common faults are. Precision does: the simulated test set is about 96% faulty windows, so its precision looks high for any detector.
